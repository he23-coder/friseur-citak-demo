# ANÁLISIS Y DECISIONES (curado por el equipo de diseño)

## Recomendaciones APLICADAS de UI UX Pro Max
1. **Tipografía**: el dominio `typography` confirma la dirección "Classic Elegant / Luxury"
   (serif editorial expresiva + sans limpia). Se aplica con **Fraunces + Manrope**
   (equivalente autoalojado de mejor rendimiento que Playfair/Inter; Manrope sustituye a
   Inter para evitar el "lenguaje visual SaaS" vetado por el brief).
2. **CTA above the fold** (patrón Persuade) — se mantiene y refuerza.
3. **Checklist pre-delivery**: iconos SVG sin emojis, cursor-pointer, hover 150–300 ms,
   contraste 4.5:1, focus visible, reduced-motion, breakpoints 375/768/1024/1440.
4. **Triple stack tipográfico editorial** (Result 2): se adopta el principio de
   "mono/eyebrow uppercase tracking-widest" para etiquetas — ya presente en el sistema.
5. **Anti-patrones**: "Cheap visuals + Fast animations" → animaciones 400–600 ms con curvas suaves.

## Recomendaciones RECHAZADAS (con motivo)
- **Estilo "Liquid Glass"** (Result 1 del design-system): el brief prohíbe glassmorphism
  como solución principal y exige minimalismo cálido editorial. Además la propia skill lo
  marca como "Performance ⚠ Moderate-Poor | Accessibility ⚠".
- **Paleta azul (#0284C7/#0EA5E9)**: fuera de marca. La identidad real es dorado + marfil +
  tinta (logo y fotografía del salón). Se sustituye por paleta champagne/ink/copper.
- **"Dark Mode (OLED) #000000" y "Cyberpunk"** (búsqueda style "dark mode"): el brief exige
  carbón cálido, nunca negro puro ni neones. Se define paleta oscura cálida propia.
- **Google Fonts CDN**: se autoalojan las fuentes vía @fontsource (DSGVO + LCP).
